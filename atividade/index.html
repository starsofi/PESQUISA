APIs:O que são e qual sua funcionalidade?

O que é uma API? Para que serve? O que é API REST? O que são endpoints? Como o Front-End utiliza uma API?

Clique abaixo para saber mais sobre os métodos utilizados:

  • O método GET é utilizado para realizar a busca ou leitura de informações já existentes em um servidor.

  • O método POST serve para enviar dados novos ao servidor com o objetivo de cadastrar ou criar um novo registro.

  • O método PUT é utilizado para atualizar ou substituir completamente todas as informações de um registro existente.

  • O método PATCH serve para realizar modificações parciais, alterando apenas campos específicos de um registro.

  • O método DELETE é enviado ao servidor quando o objetivo do sistema é excluir de forma permanente um registro.

4. Tecnologias Back-End

Nome Linguagem utilizada Principais características Vantagens Desvantagens Exemplos de utilização
Node.js JavaScript / TypeScript Ambiente de execução baseado no V8 do Chrome; assíncrono e orientado a eventos. Alta performance para aplicações em tempo real; mesma linguagem no front e back. Não é ideal para processamento pesado de CPU; gerenciamento complexo de callbacks. Sistemas de chat, streaming (Netflix) e APIs RESTful rápidas.
Django Python Framework "baterias incluídas" com foco em desenvolvimento limpo e rápido. Segurança robusta nativa; painel administrativo pronto; ORM poderoso. Monolítico e pesado para microserviços simples; curva de aprendizado inicial. Plataformas de conteúdo (Instagram) e sistemas gerenciadores de dados.
Spring Boot Java / Kotlin Framework focado em microsserviços e aplicações corporativas robustas. Altamente escalável; ecossistema gigante; segurança de tipos forte. Consumo de memória elevado; configuração inicial complexa e verbosa. Sistemas bancários, e-commerce de grande porte e sistemas de logística.
Laravel PHP Framework com sintaxe expressiva e elegante; foco na experiência do desenvolvedor. Documentação excelente; sistema de autenticação nativo; hospedagem barata. Performance inferior a ambientes compilados; pode encorajar códigos bagunçados. Aplicações MVC tradicionais, portais institucionais e SaaS de médio porte.
ASP.NET Core C# Framework modular de alta performance desenvolvido pela Microsoft. Velocidade extrema; excelente suporte empresarial; integração nativa com nuvem Azure. Dependência forte do ecossistema Microsoft; curva de aprendizado para iniciantes. Aplicações corporativas enterprise, APIs escaláveis e microsserviços em nuvem.
